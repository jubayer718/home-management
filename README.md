# 🏡 Homes Management

A modern **property management web app** built with **Next.js 15**, **React 19**, and **Tailwind CSS 4**.
It provides a sleek UI, animations, and reusable components to manage and explore property listings.

---

## 🚀 Tech Stack

* **Framework:** [Next.js 15](https://nextjs.org/) (with Turbopack)
* **UI & Styling:** [Tailwind CSS 4](https://tailwindcss.com/), `tailwind-merge`, `clsx`
* **Animations:** [Framer Motion](https://www.framer.com/motion/)
* **Icons:** [Lucide React](https://lucide.dev/), [React Icons](https://react-icons.github.io/react-icons/)
* **Components:** Radix UI, Swiper.js
* **Runtime / Package Manager:** [Bun](https://bun.sh/)

---

## 📦 Installation

```bash
# Clone the repo
git clone https://github.com/jubayer718/home-management.git
cd home-management

# Install dependencies with Bun
bun install
```

---

## 💻 Development

Run the development server with Turbopack:

```bash
bun run dev
```

Then open [http://localhost:3000](http://localhost:3000).

---

## 🏗 Build for Production

```bash
bun run build
bun run start
```

---

## 📌 Features

* 🔐 Modern **authentication-ready layout** (Login/Register)
* 🏠 Property listing grids (houses, apartments, villas, etc.)
* 📱 **Responsive navbar** with mobile/tablet drawer menu
* 🎨 Tailwind-based reusable UI components
* ⚡ Ultra-fast builds using **Next.js Turbopack**
* 🐇 Super-fast dependency management & runtime with **Bun**
